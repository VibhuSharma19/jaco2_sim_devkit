## 📦 Jaco2_moveit_config

> A ROS 2 `ament_cmake` package auto-generated using the **MoveIt 2 Setup Assistant**, containing the full motion planning configuration for the Kinova JACO2 manipulator.
---

### 🧠 <ins>Purpose

The `jaco2_moveit_config` package provides all necessary configuration to enable **motion planning** with the **MoveIt 2 framework**. It includes:

- Robot model & semantic description (URDF + SRDF)
- Kinematics, joint limits, and controller interfaces
- Plugins for **PickIK**, **TRAC-IK**, **IK-Fast**, and **Bio-IK** 
- RViz 2 configuration for visualization and interaction
- A launchable Move Group node for planning execution
<br>

### 📁 <ins>Package Structure

```bash
jaco2_gazebo
├── config/                   # MoveIt 2 configuration and planning parameters
├── launch/                   # MoveIt2 launch configuration
├── .setup_assistant          # Moveit2 setup assistant file
├── CMakeLists.txt            # Ament_cmake build script
├── package.xml               # ROS 2 package manifest
└── README.md                 # Documentation
```

### 🔍 <ins>File Descriptions

| *config/* | |
|:---- | :----- |
| [chomp_planning.yaml](./config/chomp_planning.yaml) | Chomp planner configuration |
| [initial_positions.yaml](/jaco2_moveit_config/config/initial_positions.yaml) |	Default joint configuration for the arm (e.g., "home" pose) |
| [jaco2.ros2_control.xacro](./config/jaco2.ros2_control.xacro) |	Combined robot + controller plugin interface |
| [jaco2.srdf](./config/jaco2.srdf) |	Semantic Robot Description Format (group definitions, end-effector, etc.) |
| [jaco2.urdf.xacro](./config/jaco2.urdf.xacro) | URDF file tailored for MoveIt 2 compatibility |
| [joint_limits.yaml](./config/joint_limits.yaml) | Joint velocity, effort, and positional limits |
| [kinematics_bio_ik.yaml](./config/kinematics_bio_ik.yaml) |	Bio-IK solver parameters |
| [kinematics_ikfast.yaml](./config/kinematics_ikfast.yaml) |	IKFast solver parameters (Default) |
| [kinematics_kdl.yaml](./config/kinematics_kdl.yaml) | KDL solver parameters |
| [kinematics_pick_ik.yaml](./config/kinematics_pick_ik.yaml) | PickIK solver parameters |
| [kinematics_trac_ik.yaml](./config/kinematics_trac_ik.yaml) | TRAC-IK solver parameters |
| [moveit_controllers.yaml](./config/moveit_controllers.yaml) | Defines controller handles used by MoveIt 2 during execution |
| [moveit.rviz](./config/moveit.rviz) | RViz configuration preloaded with planning panels and visuals |
| [ompl_planning.yaml](./config/ompl_planning.yaml) | OMPL motion planner configuration |
| [pilz_cartesian_limits.yaml](./config/pilz_cartesian_limits.yaml) | Limits for cartesian motion using Pilz planner |
| [pilz_industrial_motion_planner_planning.yaml](./config/pilz_industrial_motion_planner_planning.yaml) | Planning configs for Pilz industrial planner (Default) |
| [ros2_controllers.yaml](./config/ros2_controllers.yaml) | ROS 2 Control hardware interface setup |
| [sensors_3d.yaml](./config/sensors_3d.yaml) | Sensor plugin parameters (e.g., depth/point cloud integration) |
| [stomp_planning.yaml](./config/stomp_planning.yaml) | STOMP planner configuration |
|  ***launch/***  |
| [jaco2_move_group.launch.py](./launch/jaco2_move_group.launch.py) | Launches MoveIt 2’s planning pipeline, RViz, and controllers for JACO2 |

<br>

>[!Note]
> To switch between IK solvers or planning pipelines:    
> Modify the *robot_description_kinematics* and *planning_pipelines* parameters in [`jaco2_move_group.launch.py`](./launch/jaco2_move_group.launch.py).

### 📝 <ins>Key Capabilities</ins> 
- Auto-generated by MoveIt Setup Assistant (MoveIt 2.0 compliant)  
- Full support for multiple IK solvers: PickIK, TRAC-IK, KDL, Bio-IK  
- Plug-and-play Move Group launch system  
- Pre-set joint limits, planner configs, cartesian limits  
- RViz layout preloaded with motion planning panel  
- Compatible with Servo, MTC, and live teleoperation
